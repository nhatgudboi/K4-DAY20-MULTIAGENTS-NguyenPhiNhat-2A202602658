---
name: maintain-test-integrity
description: Use this skill when working on tasks that involve modifying code and running tests to ensure that the integrity of the test suite is maintained.
---
- Do not modify existing test files unless explicitly instructed.
- Add new test files if additional tests are needed to cover new functionality or bug fixes.
- Ensure all tests pass before considering the task complete.
- Regularly run the test suite during development to catch issues early.
- Review test coverage to ensure all code paths are tested.
